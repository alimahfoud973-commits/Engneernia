# الخطوط المضمَّنة

## Noto Naskh Arabic

- **الملفات:** `NotoNaskhArabic-Regular.ttf`، `NotoNaskhArabic-Bold.ttf`
- **الرخصة:** SIL Open Font License 1.1 — تسمح بالاستخدام التجاري والتضمين
  وإعادة التوزيع.
- **المصدر:** مشروع Google Noto.

### لماذا في المستودع لا مجلوباً وقت التشغيل

خادمٌ بلا إنترنت يجب أن يبقى قادراً على توليد معاينة وإصدار كشف تسوية لمهندس.
جلب خط عند الطلب يجعل مستنداً مالياً يعتمد على شبكة خارجية.

### أين يُستخدم

- `src/lib/typography/arabic.ts` — التسجيل الوحيد، وكل شيء آخر يمرّ عبره.
- `src/settlements/statement-pdf.ts` — كشف التسوية الشهري.
- `src/media/preview.ts` — العلامة المائية المحروقة في صفحات المعاينة.

### تحذير

لا تكتب نصاً عربياً عبر `pdf-lib` مباشرة. لا يملك محرك تشكيل، فيُخرج الحروف
منفصلة وبترتيب معكوس. ارسم على `@napi-rs/canvas` ثم أدرج الصورة.
