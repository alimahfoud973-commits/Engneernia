## قرارات تقنية اتُّخذت أثناء التنفيذ — Technical (TD)

| # | القرار | السبب |
|---|--------|-------|
| TD-01 | **Next.js 16** بدل 15 | `npm audit` أظهر ثغرة **عالية** في postcss عبر Next 15؛ الترقية تزيلها وتتوافق مع eslint-config-next 16 |
| TD-02 | كل مبلغ `bigint` بوحدات صغرى + عملة إلزامية | لا عدد عشري يلمس المال أبداً |
| TD-03 | النسب بـ **basis points** صحيحة (80% = 8000) | دقة 0.01% بلا كسور |
| TD-04 | يُقرَّب **طرف واحد فقط** والآخر هو الباقي | يجعل `مهندس + منصة = السعر` هوية حسابية لا احتمالاً |
| TD-05 | توزيع **الباقي الأكبر** (Hamilton) بين عدة مهندسين مع فاصل ترتيب ثابت | لا يضيع ولا يُخلق قرش؛ نتيجة حتمية مستقلة عن ترتيب الإدخال |
| TD-06 | عميل قاعدة البيانات **كسول** (lazy) | البناء و CI يجب ألا يحتاجا أسرار الإنتاج |
| TD-07 | قبول 4 تنبيهات `moderate` في `drizzle-kit` | محصورة في esbuild المُجمَّع داخل أداة تطوير لا تعمل في الإنتاج؛ «الإصلاح» يعني الرجوع لنسخة 0.18.1 القديمة. CI يفشل عند `high` فأعلى فقط |
| TD-08 | التحقق من البيئة `fail-fast` + `server-only` | سرّ لا يمكن أن يصل للمتصفح بالخطأ؛ خطأ إعداد يظهر عند الإقلاع لا عند الدفع |
