# خارطة الطريق — Roadmap

كل مرحلة تنتهي بزيادة قابلة للعرض والاختبار، ومعيار خروج صريح، ثم **توقّف للمراجعة**.

| المرحلة | المحتوى | معيار الخروج | الحالة |
|---|---|---|---|
| **P0** | الأساس: مستودع، Docker، إعدادات، تعريب RTL، نظام تصميم، **النواة المالية**، CI | البناء والاختبارات و lint تمرّ؛ عزل صلاحيات قاعدة البيانات مُثبت | ✅ **مكتملة** |
| **P1** | الهوية، الجلسات، RBAC، سياسات RLS، سجل التدقيق، تحديد المعدل، 2FA للمالك | مصفوفة الصلاحيات كاملة تمرّ — **بما فيها اختبارات RLS مع تعطيل طبقة السياسة عمداً** | ✅ **مكتملة** |
| **P2** | التخصصات، شجرة التصنيفات، المنتجات، تاريخ الأسعار، آلة حالات النشر، **سطح تصفّح عام أساسي** | منتج يمرّ مسودة ← مراجعة ← نشر؛ تغيير السعر يُسجَّل ويُشعر مهندسه وحده | ✅ **مكتملة** |
| **P3** | التخزين الخاص، الفحص، مولّد المعاينة، الختم المائي، الروابط الموقّعة | PDF من 120 صفحة ينتج معاينة 5 صفحات مُنقّطة بعلامة مائية؛ لا مسار يصل للأصل بلا تصريح | التالية |
| **P4** | الواجهة العامة: الرئيسية، بوابات التخصصات، صفحة المنتج، البحث والفلاتر | رحلة تصفّح ← معاينة على الجوال والحاسوب؛ البحث يؤدي على 5000 منتج | |
| **P5** | الطلبات، مدير طرق الدفع، التحويل اليدوي، واتساب، إثبات الدفع، الاستحقاقات، التنزيل الآمن | شراء يدوي كامل يوافق عليه المالك فيمنح التنزيل؛ تعطيل طريقة دفع يخفيها فوراً بلا نشر | |
| **P6** | اتفاقات العمولة، كتابة اللقطات، الدفتر مزدوج القيد، سلسلة التجزئة، الاسترجاع، تقارير المالك | **اختبار ثبات اللقطة**: بِع، ثم غيّر السعر والعمولة، ثم تأكد أن كل رقم تاريخي لم يتغير. الدفتر يساوي صفراً | |
| **P7** | توليد الفترات، دورة حياة التسوية، تسجيل الدفع، الاسترداد المؤجل، لوحة المهندس، لوحة المالك | ثلاثة أشهر محاكاة تُسوّى بشكل صحيح، بما فيها استرجاع يصل بعد تسوية شهره | |
| **P8** | الإشعارات، التقييمات، SEO، الأداء، النسخ الاحتياطي، مراجعة أمنية، أدلة التشغيل | تمرين استعادة من نسخة احتياطية ينجح؛ قائمة الفحص الأمني معتمدة؛ النشر للإنتاج | |

## لماذا هذا الترتيب

- **P1 قبل كل شيء**: كل مرحلة لاحقة تقف على صحة نموذج الصلاحيات.
- **P3 قبل P5**: التحقق من الاستحقاق بلا معنى إن كان الملف متاحاً أصلاً.
- **P6 قبل P7**: التسوية مجرد عرض فوق دفتر صحيح.

لا شيء يلمس المال قبل أن تُختبر الأرضية التي يقف عليها.


## ملاحظة على نطاق P2

أُضيف **سطح تصفّح عام أساسي** (رئيسية، بوابات التخصصات، صفحة منتج، بحث بالعنوان)
ضمن P2 لإتاحة المعاينة المبكرة. البحث بالفلاتر المتقدمة، والتلميع البصري الكامل،
والهوية البصرية النهائية (OPEN-8) تبقى في **P4**.
