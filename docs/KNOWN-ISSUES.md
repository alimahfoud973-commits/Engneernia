# مسائل معروفة — Known Issues

## KI-1 · صفحة خطأ جذرية مخصّصة تُفشل البناء بشكل متقطّع

**الحالة:** مُتجنَّبة — نستخدم صفحة Next الافتراضية.

**الوصف:** إضافة `src/app/global-error.tsx` تجعل `next build` يفشل أحياناً عند
التصيير المسبق لـ`/_global-error` بالخطأ:

```
TypeError: Cannot read properties of null (reading 'useContext')
Export encountered an error on /_global-error/page
```

**ما جُرِّب:**

| المحاولة | النتيجة |
|---|---|
| نسخة كاملة بزر `reset` | فشل ثابت |
| نسخة بلا معالجات أحداث | نجح مرتين ثم **فشل في المرة الثالثة** |
| نسخة بسيطة جداً | نجح |
| تعطيل إضافة `next-intl` | لم يُغيّر شيئاً |
| **حذف الملف** | **نجح دائماً** |

**التشخيص:** المشكلة في تفاعل `global-error` مع التصيير المسبق، لا في التعريب.
جذر المشكلة غير محسوم — وهذا سبب كافٍ لعدم الاعتماد عليه الآن.

**القرار:** بناء متذبذب أسوأ من صفحة خطأ افتراضية. صفحة Next الافتراضية عامة
ولا تسرّب أي أثر تقني. تُعاد المحاولة في **P8** مع ترقية Next، ومع اختبار
يشغّل البناء عدة مرات للتأكد من الثبات لا من نجاح واحد.

**الأثر:** خطأ على مستوى الجذر يعرض صفحة Next الإنجليزية العامة بدل رسالة
عربية. حدود الأخطاء داخل التطبيق (`error.tsx` لكل مسار) غير متأثرة ويمكن
إضافتها بأمان.
