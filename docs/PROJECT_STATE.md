## ٤. قرارات يجب عدم مخالفتها

- **الدخول**: بالبريد + كلمة المرور فقط، ودخول مباشر بعد كلمة المرور الصحيحة.
  لا تأكيد بريد ولا رمز OTP بالبريد. رسالة التسجيل موحّدة (لا تكشف وجود البريد)،
  ولا بريد يُرسل عند التسجيل. عنوان مسجّل لا يُعدَّل بإعادة التسجيل (لا استيلاء).
- **TOTP للمالك يبقى إلزامياً للوحة الإدارة** (`requireOwner`). إلغاؤه موضوع منفصل
  لم يُقرَّر. TOTP للمستخدمين الآخرين فقط لمن فعّله.
- **الدخول باسم المستخدم أو الهاتف = المرحلة 6**، مؤجّلة. لا أعمدة لها في القاعدة.
- **المنتج المجاني** يكتمل فوراً بلا دفعة (`app_complete_free_order`).
- **لا بيع بلا اتفاق عمولة سارٍ** للمنتج المدفوع، ولا نسبة عمولة افتراضية في الكود.
- **بيانات طريقة الدفع تُنسخ على الدفعة** عند إنشائها؛ تعديل الطريقة لا يمس طلباً قائماً.
- **رقم واتساب يُقرأ من الإعدادات لحظة بناء الرابط**، ولا يُنسخ على الطلب.
- **المعاينة تُقدَّم من أصل الموقع نفسه دائماً** (تُقرأ من التخزين وتُبثّ، لا تحويل
  إلى رابط موقّع). وحدها قابلة للتضمين، ومن الموقع نفسه فقط
  (`frame-ancestors 'self'` + `X-Frame-Options: SAMEORIGIN`). كل مسار آخر
  `X-Frame-Options: DENY`، و CSP الصفحة `frame-src 'self'` لا تسمّي أي مضيف تخزين.
  يحرس ذلك `src/lib/security/framing.test.ts`.
- **الملف الأصلي**: رابط موقّع 60 ثانية بعد التحقق من الملكية، و`attachment`.
  لا bucket عام.
- **التخزين**: `file://` هو الافتراضي المحلي. خدمة S3 المحلية وCI هي
  `rustfs/rustfs:1.0.0` (مثبّتة)، وتهيئة الـ buckets بـ `amazon/aws-cli:2.37.4`.
  لا MinIO: صوره أُزيلت من Docker Hub وquay.io يرد 401 (تحقّق المالك على جهازه).
- **`src/finance/policy.ts` تُرك عمداً** دون تعديل في F4 (قيمه الواقعية تُقرأ صحيحاً).
- **سلوك `tax.rateBp` لم يتغيّر** في F4، ومثبّت باختبار.

## ٥. قواعد العمل التي حدّدها المالك

- **اكتشاف ← إصلاح ← اختبار ← قبول ← إغلاق.** تدقيق أولاً، ولا تعديل قبل دليل.
- **مشكلة مستقلة تظهر أثناء بند: تُسجَّل ولا تُصلَح** ضمنه.
- **لا ميزات جديدة.** لا تحسينات تجميلية تُقدَّم على أنها أخطاء.
- **commit/push فقط بإذن المالك لكل بند.** العمل على `main`، مع `git diff --check`
  و`npm run verify` قبل الـ commit، والتأكد بعد الـ push أن `main = origin/main`
  وأن CI أخضر.
- **ممنوع**: force push، إعادة كتابة التاريخ، حذف فروع، التراجع عن إصلاحات سابقة.
- **لا تُمَس** `package.json` و`package-lock.json` إلا حين يكون البند نفسه عنهما
  وبموافقة (كما في إصلاح SWC). **`CLAUDE.md` لا يُعدَّل إلا بطلب صريح من المالك.**
- **لا إضعاف لـ RLS**، ولا دالة `SECURITY DEFINER` جديدة إلا بضرورة مُثبتة.
- **لا ترحيل** إلا بضرورة، ويُذكر السبب للمالك قبل التنفيذ.
- **التجارب على قواعد بيانات مؤقتة** تُحذف بعدها، لا على قاعدة المالك.

## ٨. معلومات تقنية للمتابعة

**التشغيل المحلي**
```bash
docker compose up -d            # PostgreSQL + RustFS + تهيئة الـ buckets
docker compose up -d postgres   # Postgres وحده (التخزين الافتراضي file://)
npm run db:migrate              # بعد كل pull فيه ترحيل جديد
npm run verify                  # قبل أي commit
npm run test:integration        # يحتاج قاعدة حقيقية
```
- لاستعمال RustFS بدل القرص: `STORAGE_ENDPOINT=http://localhost:9000` في `.env.local`.
  المفاتيح `minioadmin` وأسماء الـ buckets كما في `.env.example`.

**CI** (`.github/workflows/ci.yml`): خدمتا `postgres:16-alpine` و`rustfs/rustfs:1.0.0`،
ثم npm ci ← typecheck ← lint ← وحدة ← إثبات RLS ← ترحيلات ← seeds
(`seed:catalog` `seed:demo` `seed:scale`) ← إنشاء الـ buckets ← تكامل ← بناء ← `npm audit --audit-level=high`.

**قاعدة مؤقتة للتجارب** (كما يفعل CI): أنشئ القاعدة، امنح `migrator` كل الصلاحيات
و`app_user` الاتصال، واجعل `migrator` مالك `public` مع
`ALTER DEFAULT PRIVILEGES FOR ROLE migrator ... TO app_user` (انظر
`docker/postgres/init/01-roles.sql`)، ثم `db:migrate` والـ seeds، واحذفها بعد الانتهاء.
`seed:demo-media` يحتاج صف مالك موجوداً.

**مزالق مُثبتة**
- `next dev` يُلحق كتلة قواعد بـ `CLAUDE.md` حين يكتشف أنه يعمل داخل وكيل ذكي؛
  شغّله بـ `env -i PATH="$PATH" HOME="$HOME" npx next dev` لتفاديه.
- Drizzle يحلّل عمود `jsonb` مرتين: نص مثل `"2026"` يعود رقماً. اقرأ الإعدادات
  النصية بـ `${settings.value}::text` ثم `JSON.parse` (كما في `settings.ts`
  و`tax-policy.ts`).
- header في `next.config.ts` يتغلّب على header يضعه المسار لنفس المفتاح.
- `npm` يرفض بـ `EBADPLATFORM` أي تبعية مباشرة غير اختيارية لمنصة أخرى.

**بيئة Claude Code السحابية** (خاص بها، مُتحقَّق منه):
- Postgres المحلي: `bash scripts/dev-db.sh` (قد يتوقف عند إعادة تشغيل الحاوية).
